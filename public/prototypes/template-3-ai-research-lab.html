Architectural Dossiers

DOSSIER #1 · DISTRIBUTED RETRIEVAL Repository

ClipSense AI: Two-Stage Dense Video Retrieval

Addresses search latency bottlenecks over fragmented video transcript transcripts. Integrates thread-pool parallelism with Qdrant vector embeddings, followed by a second-stage cross-encoder re-ranking step engineered inside a sub-80 MB serverless RAM container.

DOSSIER #2 · SYSTEMS & STORAGE Repository

Mini Database Storage Engine: B+Tree with Write-Ahead Logging

A C++20 disk-backed key-value store engineered without external database libraries. Features a custom buffer pool manager managing 4KB page frames, sequential WAL commit logging for crash recovery, and doubly-linked leaf nodes for linear range queries.
