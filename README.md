# Ishaan Shailesh Phaye — Portfolio

Single-page Systems & Applied AI Engineer portfolio built with Next.js 15 (App Router), TypeScript, Tailwind CSS v4, Framer Motion, Groq AI, Upstash Redis, and Resend.

## Quick Start

```bash
npm install
cp .env.example .env.local
# Fill in GROQ_API_KEY and RESEND_API_KEY in .env.local
npm run dev
```

See `ANTIGRAVITY_HANDOFF.md` for the complete build, verification, and deployment runbook.
